## 📌 What is SQL Planner?

**SQL Planner** is an all-in-one, browser-based database observability and administration suite designed for DBAs, DevOps, SysAdmins, and Engineering teams. It replaces expensive, fragmented enterprise tools with a single unified platform running securely inside your infrastructure.

Whether managing mission-critical on-premise instances or cloud-hosted DBs (Azure SQL, AWS RDS), SQL Planner delivers deep visibility into instance health, query performance bottlenecks, deadlock root causes, index fragmentation, automated backup verification, and database schema diffs.

> **💡 Why Choose SQL Planner?**
> - **Free for Developers & Students:** 100% free for individual developers, students, educators, and personal learning/evaluation.
> - **5x Lower Enterprise TCO:** Replaces expensive legacy stacks (Redgate, SolarWinds, Idera) at up to 80% lower cost with zero predatory per-core penalties.
> - **90% Faster MTTR:** Pinpoint CPU spikes, I/O bottlenecks, lock escalations, and expensive queries in seconds.
> - **100% On-Premise & Air-Gapped Safe:** Zero mandatory cloud telemetry. Your proprietary database schemas and data never leave your firewall.
> - **Zero-Footprint Web UI:** Access your dashboards and query studio from any browser on Windows, Mac, Linux, or Mobile.

## ⚡ Core Capabilities

### 1. 🔍 Unified Multi-Platform Observability
Monitor enterprise database engines alongside operating systems and infrastructure under one pane of glass:
- **Databases:** Microsoft SQL Server (2012 onwards, Always On AG), PostgreSQL, Oracle, MySQL, Azure SQL Database, AWS RDS.
- **Operating Systems & Web Services:** Windows Server metrics (CPU, RAM, Disk I/O, Page Life Expectancy), Linux OS performance, IIS Web Servers, and critical Windows Services.
- **Proactive Alerts:** Over 100+ built-in proactive threshold alerts sent via Email, Webhooks, or ITSM (ServiceNow).
- 📺 **[Watch Observability Demo Video](https://youtu.be/cwHvKUtbFcw)**

### 2. 🧠 AI-Assisted & Rule-Based Query Tuning
Eliminate guesswork when troubleshooting high CPU, high memory, or sluggish queries:
- Automatically captures slow, expensive, and long-running queries with execution plans.
- Identifies implicit data type conversions, heavy table scans, and missing indexes.
- Provides actionable T-SQL query rewrite suggestions and missing index scripts with estimated performance gains and risk analysis.
- 📺 **[Watch AI Query Tuning Demo Video](https://www.youtube.com/watch?v=V0csnq3mdCo)**

### 3. 🔒 Deadlock & Blocking Root Cause Analyzer
- Real-time deadlock graphs with victim detection and locking process hierarchy.
- Identifies blocking chains down to the exact SQL statement and transaction isolation level.
- Historical replay of blocking and deadlock incidents for post-mortem investigations.

### 4. 🗄️ Automated Backups with Auto-Restore Integrity Testing
- Centralized scheduling for Full, Differential, and Transaction Log backups.
- **Auto-Restore Validation:** Automatically test-restores backup files onto a staging or sandbox server to verify backup integrity, proving your RPO and RTO disaster recovery readiness.
- Intelligent backup retention rules to prevent disk saturation.

### 5. 🧩 Schema Compare & Visual Database Designer
- Side-by-side visual schema comparison and synchronization across Dev, Staging, and Production environments.
- Generates safe deployment migration scripts with dependency ordering.
- Built-in visual ERD and database modeling tools directly in your browser.
- 📺 **[Watch Schema Compare Demo Video](https://www.youtube.com/watch?v=_zFRpcNPHG4)**

### 6. 📊 Embedded Business Intelligence (BI) & Live Dashboards
- Create custom operational and business KPI dashboards with native SQL queries.
- Share interactive, secure reports across teams without paying for separate third-party BI user licenses.
- 📺 **[Watch Embedded BI Demo Video](https://www.youtube.com/watch?v=KpDHGjIGzjw)**

### 7. 🛠️ Index Fragmentation Analysis & Automated Maintenance
- Visual fragmentation heatmaps across all database tables and indexes.
- Customizable smart maintenance schedules (Reorganize vs Rebuild based on fragmentation thresholds and page count) during off-peak windows.

### 8. 📝 DBA Handover Notes & Maintenance Automation
- Centralized shift-handover logbook for DBAs and DevOps teams.
- Tracks configuration changes, patching schedules, and maintenance tasks to eliminate team silos.

## ⚙️ Quick Installation (3-Step Setup)

Installing SQL Planner takes less than 5 minutes on any Windows machine or server:

### Step 1: Configure Prerequisites
Run the included batch script as Administrator to configure IIS, ASP.NET, and Windows features automatically:
```cmd
Install_Configure_IIS.bat
```

### Step 2: Run Setup
Execute the installer:
```cmd
SQLPlannerSetup.exe
```
Follow the on-screen wizard to specify the database connection for the SQL Planner repository.

### Step 3: Access SQL Planner
Open your preferred browser on any computer, tablet, or phone in your network:
```
http://localhost/sqlplanner
```
*(Or replace `localhost` with your server's IP / hostname / internal domain).*

## ❓ Frequently Asked Questions (FAQ)

<details>
<summary><strong>Is SQL Planner free?</strong></summary>
SQL Planner is 100% free for individual developers, students, educators, and personal learning/evaluation. For production, commercial, and enterprise organization-wide deployments, SQL Planner offers flexible, transparent enterprise licensing at a fraction of legacy vendor costs (up to 80% lower than Redgate or SolarWinds). Visit <a href="https://mssqlplanner.com">mssqlplanner.com</a> for enterprise quotes and licensing.
</details>

<details>
<summary><strong>Does SQL Planner install intrusive background agents on my production database servers?</strong></summary>
No. SQL Planner uses an agentless architecture. It collects metrics remotely via lightweight, low-impact system queries and DMVs (Dynamic Management Views), ensuring zero performance penalty on your production workloads.
</details>

<details>
<summary><strong>Does my sensitive database information or telemetry get sent to external cloud servers?</strong></summary>
Never. SQL Planner is engineered for strict enterprise compliance (BFSI, Healthcare, Defense, DPDP, HIPAA, and GDPR). It installs 100% on-premises or inside your private VPC/VNet and can operate in completely air-gapped environments with zero external outbound internet connections.
</details>

<details>
<summary><strong>Can I manage and query databases from my Mac, Linux laptop, or tablet?</strong></summary>
Yes. SQL Planner is 100% browser-based. Once installed on a Windows server, you can log in, run queries in the web studio, review alerts, and inspect deadlocks from any device.
</details>
